# Proceso de onboarding — NubeTech

Primer día: el manager directo agenda una reunión de bienvenida y el equipo de IT entrega notebook, accesos a Slack, Google Workspace y el repositorio de código correspondiente al equipo.

Primera semana: el nuevo ingreso completa el curso interno "NubeTech 101" (2 horas, obligatorio) sobre cultura, herramientas y seguridad informática básica.

Primer mes: se define un "buddy" (compañero de otro equipo) para consultas informales, y se agenda una revisión de 30 días con RRHH para feedback temprano.

El período de prueba dura 3 meses, con evaluación formal a los 90 días entre manager y RRHH.
